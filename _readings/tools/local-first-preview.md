## Overview

A local preview shortens the path between editing a token and seeing its effect
on a real page.

## Workflow

1. Start the bundled preview command.
2. Check both visual environments.
3. Open a project, note, and reading entry.
4. Run the link and privacy checks before publishing.

## Verdict

The fastest useful review loop is the one that exercises the actual Jekyll
site without requiring a deployment.
